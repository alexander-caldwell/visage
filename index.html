Visage

Custom visualisations for Looker

A living suite of charts Looker's built-in options cannot draw, each a single JavaScript file with nothing to bundle and nothing to load. Every chart here is live: the file in this repo is rendered on this page by the same calls Looker makes, and its controls are read out of the file rather than written down. Search by name, by the data it needs, or by what you are trying to show.

Register one

Looker admin, Platform, Visualizations, Add. Use the chart's id, any label you like, and this URL:

https://cdn.jsdelivr.net/gh/alexander-caldwell/visage@1/<id>.js

Why @1

@1 tracks the newest 1.x release, so a fix reaches your instance without anyone editing the registration. Pin an exact tag when the file must never change under you.

Hosting in full

How they are built

Written against captured Looker data, rendered headlessly, screenshotted, and put through a suite of checks, each one a failure that happened in a real instance.

The approach, and what was rejected

The figures are invented sample data, not anyone's numbers. The dashboard switch shows what each chart does on a dark dashboard: it reads the background of the tile it is drawn into rather than the viewer's system setting.
