Visage

Custom visualisations for Looker

Nine charts Looker's built-in suite cannot draw, each a single JavaScript file with no dependencies. Every chart below is live: it is loaded from the CDN and rendered on this page by the same calls Looker makes, and its controls are read from the file itself.

Register one

Looker admin, Platform, Visualizations, Add. Use the chart's id shown below, any label you like, and this URL:

https://cdn.jsdelivr.net/gh/alexander-caldwell/visage@1/<id>.js

Why @1 and not a version

@1 tracks the newest 1.x release, so a fix reaches your instance without anyone editing the registration. Pin an exact tag such as @v1.8.0 when you need the file never to change.

One caveat

The CDN caches which release @1 points at for about 12 hours, and browsers hold the file for up to 7 days. A change is not instant. Register a pinned tag while iterating, then move back to @1.

Treemap

Box area from one measure, colour from another, both figures printed in the box.

Marimekko

Width carries one measure, height the other, so each column's area is a third quantity.

Dumbbell

Two measures per row on one shared scale, joined by a connector showing the gap.

Histogram

Distribution of one measure, binned, with optional mean, median and percentile lines.

Line

One line per series across an ordered dimension.

Stacked Area

One band per series, stacked, in absolute values or share of total.

Grouped Column

One group per dimension value, one column per measure.

Scatter

One dot per row, two measures placing it, a third sizing it.

Bullet Bar

Actual against target, one row per dimension value.

The figures on this page are invented sample data, not anyone's numbers. Switching the button above between light and dark shows what each chart does on a dark dashboard: it reads the background of the tile it is drawn into rather than the viewer's system setting.

Every chart passes a suite of 21 checks covering re-mounted tiles, tiles that measure zero before layout, dark and light dashboards, narrow tiles, empty and null data, and text overflowing its tile.
